# Proyecto: Simulación y Mitigación de SQL Injection (SQLi)

**Institución:** Universidad Estatal de Milagro (UNEMI)
**Asignatura:** SEGURIDAD INFORMATICA
**Año:** 2026

## Descripción del Proyecto
Este repositorio contiene un entorno web controlado desarrollado con Python, Flask y SQLite. El objetivo es simular una vulnerabilidad de Inyección SQL (SQLi) en un formulario de login, demostrar su explotación mediante un script, y aplicar la mitigación correspondiente mediante consultas parametrizadas.

**Advertencia Ética:** Este proyecto es estrictamente académico. El uso de estas técnicas fuera de este entorno controlado constituye un delito informático.
